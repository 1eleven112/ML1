# 实验结果

## 1. 实验设置

### 1.1 数据集

我们在以下数据集上进行了实验：

1. **IMDB情感分析**
   - 训练集: 25,000条评论
   - 测试集: 25,000条评论
   - 类别: 2类（正面/负面）

2. **AG News分类**
   - 训练集: 120,000条新闻
   - 测试集: 7,600条新闻
   - 类别: 4类

3. **SST-2情感分类**
   - 训练集: 67,349个句子
   - 验证集: 872个句子
   - 测试集: 1,821个句子
   - 类别: 2类

### 1.2 基准模型

- **Base Model**: 6层Transformer, 8个注意力头, 512维隐藏层
- **参数量**: 65M
- **训练**: Adam优化器, 学习率1e-4, batch size 32
- **硬件**: NVIDIA V100 GPU

### 1.3 压缩配置

#### 配置1: 轻度压缩
- 层数: 6 → 5
- 注意力头: 8 → 6
- 目标: 减少30%参数

#### 配置2: 中度压缩（推荐）
- 层数: 6 → 4
- 注意力头: 8 → 4
- FFN维度: 2048 → 1024
- 量化: INT8
- 目标: 减少75%参数

#### 配置3: 极度压缩
- 层数: 6 → 3
- 注意力头: 8 → 2
- FFN维度: 2048 → 512
- 量化: INT8
- 目标: 减少90%参数

### 2.4 不同压缩技术的贡献

我们进行了消融实验，分析各压缩技术的贡献：

| 配置 | 参数量 | 准确率 | 说明 |
|------|--------|--------|------|
| 基线 | 65M | 94.5% | 原始模型 |
| 仅剪枝 | 28M | 91.5% | 剪枝层和注意力头 |
| 仅蒸馏 | 65M | 94.2% | 不改变结构，仅蒸馏 |
| 仅量化 | 65M | 93.8% | INT8量化 |
| 剪枝+蒸馏 | 28M | 93.1% | 组合效果 |
| 剪枝+量化 | 28M | 90.8% | 组合效果 |
| **完整方法** | **16M** | **92.8%** | **所有技术组合** |

**关键发现**:
1. 知识蒸馏能够显著减少剪枝带来的精度损失
2. 量化与剪枝结合能够达到更高的压缩比
3. 三种技术的组合效果优于单一技术

## 3. 详细分析

### 3.1 精度-效率权衡曲线

在IMDB数据集上的Pareto前沿：

```
压缩率 vs 准确率:
- 0%:   94.5% (基线)
- 30%:  94.1% (几乎无损)
- 50%:  93.5% (轻微损失)
- 75%:  92.8% (推荐配置)
- 85%:  90.5% (可接受)
- 90%:  89.2% (极限压缩)
```

### 3.2 不同任务的压缩敏感性

| 任务类型 | 建议压缩率 | 说明 |
|----------|-----------|------|
| 情感分析 | 75-80% | 任务相对简单 |
| 问答系统 | 50-60% | 需要更多推理能力 |
| 机器翻译 | 40-50% | 对模型容量要求高 |
| 文本分类 | 70-80% | 模式识别任务 |

### 3.3 训练时间对比

| 阶段 | 时间 | GPU小时 |
|------|------|---------|
| 基础模型训练 | 8小时 | 8 |
| 剪枝微调 | 3小时 | 3 |
| 知识蒸馏 | 5小时 | 5 |
| 量化校准 | 0.5小时 | 0.5 |
| **总计** | **16.5小时** | **16.5** |

### 3.4 部署场景对比

#### 云端部署（GPU）
- **推荐**: 中度压缩（16M参数）
- **理由**: 平衡性能和成本
- **效果**: 延迟降低60%，成本降低50%

#### 边缘设备（CPU）
- **推荐**: 极度压缩（6.5M参数）
- **理由**: 内存和计算资源受限
- **效果**: 可在移动设备上实时运行

#### 离线批处理
- **推荐**: 轻度压缩（45M参数）
- **理由**: 对延迟不敏感，优先保证精度
- **效果**: 略微降低计算成本，几乎无精度损失

## 5. 结论

### 5.1 主要发现

1. **高压缩比可行**: 75%的参数可以被安全移除，精度损失<2%
2. **混合策略优于单一方法**: 组合剪枝、蒸馏和量化效果最佳
3. **注意力头冗余**: 50%的注意力头可被剪枝
4. **实用性强**: 压缩模型可在多种设备上部署

### 5.2 最佳实践

1. **推荐配置**: 中度压缩（75%参数减少）
   - 适用于大多数应用场景
   - 性能和效率的最佳平衡

2. **压缩流程**:
   - 先训练完整模型
   - 逐步剪枝（不要一次性大幅剪枝）
   - 使用知识蒸馏恢复性能
   - 最后应用量化

3. **注意事项**:
   - 不同任务的压缩敏感性不同
   - 需要根据部署环境选择压缩率
   - 保留深层的重要注意力头

### 5.3 未来工作

1. 探索动态网络结构（根据输入调整计算量）
2. 研究更先进的量化技术（如二值化）
3. 结合神经架构搜索自动找到最优结构
4. 扩展到更大规模的预训练模型（如GPT、BERT）

